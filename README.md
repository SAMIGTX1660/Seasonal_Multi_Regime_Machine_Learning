# Seasonal Multi-Regime Machine Learning for Daily PM2.5 Prediction in Dhaka, Bangladesh

This repository contains the code, dataset links, and final academic report for the project **"Seasonal Multi-Regime Machine Learning for Daily PM2.5 Prediction in Dhaka, Bangladesh"**, developed as part of the CSE477 (Data Mining) course at East West University, Bangladesh.

## 📌 Project Purpose

Dhaka experiences extreme seasonal variations in air pollution (PM2.5). The standard methodological approach in air quality prediction is to train a **Single Global Model** on a full year of data. 

The purpose of this research is to investigate whether a **Multi-Regime Framework**—which physically decouples the data into distinct seasonal periods (Winter, Monsoon, Transition) and trains independent specialist models—can outperform a single global model. We evaluated three tree-based algorithms (Random Forest, XGBoost, and LightGBM) to determine if the benefits of seasonal specialization are universal or algorithm-dependent.

### Key Findings:
* **Algorithm Dependence:** Regime specialization does *not* universally improve prediction. Global Random Forest was the best overall model (RMSE: 8.89), and splitting it into regimes actually worsened its performance.
* **Gradient Boosting Success:** Conversely, Multi-Regime routing significantly improved XGBoost (8.7% overall error reduction) and LightGBM (6.31% reduction).
* **Winter Spikes:** The performance gains for XGBoost and LightGBM were heavily concentrated in the high-pollution **Winter_Dry** regime, proving that specialized models are better at capturing extreme pollution variance in boosting architectures.

## 📊 Dataset

We use the **Dhaka Air Quality Historical Dataset** from Kaggle:
* **Source:** [`nitirajkulkarni/dhaka-bd-1185241`](https://www.kaggle.com/datasets/nitirajkulkarni/dhaka-bd-1185241)
* **Target Variable:** `pm2_5` (Continuous regression in µg/m³)
* **Features Used:** Carbon monoxide, nitrogen dioxide, sulphur dioxide, ozone, aerosol optical depth, dust, UV index, day of week, PM2.5 lag-1, PM2.5 lag-7, and a 3-day rolling PM2.5 mean.
* *Note: The code uses `kagglehub` to download the dataset automatically.*
